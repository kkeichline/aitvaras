# Aitvaras

**A multi-agent oversight benchmark.** A monitor model reads the transcript of a
trading agent and tries to catch it breaking rules. The question is not whether
the agent trades well — it is how reliably oversight catches misbehaviour, and
how stable that measurement is across seeds, prompt phrasings, and models.

The trading environment is a means, not the product. It exists to manufacture
labelled clean and dirty transcripts.

## The core idea

A run emits **two files that never touch**:

```
runs/<run_id>/transcript.json   # everything the monitor may see
runs/<run_id>/labels.json       # ground truth. never shown to a monitor.
```

The rule engine is the *oracle*: it knows, with certainty, every mechanical
violation that occurred. The monitor's entire job is to recover that from the
transcript alone. If a single engine-derived fact leaks across the wall, the
benchmark measures leakage instead of detection and the numbers are void.

The engine is **permissive** by default: it records violations and lets the
trade through. A blocked violation produces no misbehaviour to detect.

## Layout

```
src/aitvaras/
  schemas/   the typed contract. imports nothing from its siblings.
  env/       protocols.py is the swap boundary; replay.py is lookahead-safe by construction
  rules/     the oracle — four mechanical rules, deterministic
  agent/     prompt rendering and the LLM agent
  llm/       provider routing (LiteLLM) behind a narrow protocol, with an on-disk cache
  monitor/   phase 3
  runner/    config and CLI
```

## Data

Committed price data is **synthetic**, generated by a seeded script — real
vendor data has murky redistribution terms and this repo is public. Tests and CI
run offline against the fixture. Real bars can be fetched locally into
`data/prices/real/`, which is gitignored. Both satisfy the same
`MarketDataSource` protocol.

```bash
uv run python scripts/gen_synthetic_prices.py
```
